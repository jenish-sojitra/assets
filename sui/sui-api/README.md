# @exodus/sui-api &middot; [![npm version](https://img.shields.io/badge/npm-public-blue.svg?style=flat)](https://www.npmjs.com/package/@exodus/sui-api)

The **sui-api** provides utilities for interacting with the Sui blockchain.
It offers functionality to query transaction data, monitor network health, and broadcast transactions

---

## Installation

Install the package via `yarn`:

```bash
yarn add @exodus/sui-api
```
